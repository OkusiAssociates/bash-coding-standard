`★ Insight ─────────────────────────────────────`
Two details worth noting from this pass: first, BCS0303 exists specifically because `[[ ]]` in Bash performs no word-splitting or pathname expansion on its operands — this is what makes `[[ ${1:-} == --version ]]` safe unquoted, whereas the same expression inside single-bracket `[ ]` would need quoting to avoid breaking on empty/multi-word values. Second, the `--` in `local -- name=...` (BCS0201) is a pure convention with zero functional effect — it's the "explicit string type" counterpart to `-i`/`-a`/`-A`, existing only so a reader (human or AI) can tell at a glance that the omission of a type flag was a deliberate choice, not an oversight.
